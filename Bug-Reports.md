# Bug Report: Player can climb through wall and access restricted area

## Description
Player is able to move upward along a wall by repeatedly pressing the jump key, allowing access to locations that should be inaccessible at the current stage of the game.

## Steps to Reproduce
1. Launch the game The Planet Crafter
2. Find any solid wall or vertical surface
3. Stand very close to the wall
4. Repeatedly press the "Space" key (jump)
5. Continue pressing until the character starts moving upward

## Expected Result
Player should not be able to move vertically along walls or access restricted areas.

## Actual Result
Player moves upward along the wall and can reach restricted locations.

## Environment
- Game: The Planet Crafter
- Platform: PC
- Input: Keyboard (Space key)

## Severity
High (breaks game progression)

## Notes
This issue allows players to bypass progression and enter locked areas earlier than intended.

## Frequency
100% (always reproducible)
