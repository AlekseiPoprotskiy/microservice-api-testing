# Microservice API Testing Platform

Backend-oriented QA project focused on distributed systems testing.

## Stack

* Postman
* REST API
* PostgreSQL
* Docker
* Linux/Bash
* GitHub Actions

---

# Project Goals

* API validation
* SQL verification
* troubleshooting
* monitoring
* backend QA workflows

## API Testing

* positive scenarios
* negative scenarios
* authorization checks
* response validation
* status code validation

## SQL Validation

* duplicate detection
* aggregation checks
* reconciliation validation

## Monitoring & Troubleshooting

* health check scripts
* log analysis
* API monitoring
